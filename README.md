# ATM Management System

A robust and interactive desktop application that simulates a real-world Automated Teller Machine (ATM). Built with C# and Windows Forms, this project demonstrates core Object-Oriented Programming (OOP) principles, secure user authentication, and transaction management.

## 🚀 Features

* **Secure Authentication:** Users must log in using a valid Account Number and a 4-digit PIN.
* **Interactive Numpad:** A built-in virtual keypad for touch-friendly or mouse-driven inputs.
* **Balance Inquiry:** Real-time checking of current account balances.
* **Cash Withdrawal:** Users can withdraw amounts with built-in validation to prevent overdrafts (Insufficient Funds checking).
* **Transaction Receipts:** Automatically generates detailed transaction records with date and time stamps.
* **Encapsulation & OOP:** Designed with clean code architecture, separating the User Interface logic from the core Business Logic (`Account` class).

## 🛠️ Tech Stack

* **Language:** C#
* **Framework:** .NET (Windows Forms / WinForms)
* **IDE:** Visual Studio
